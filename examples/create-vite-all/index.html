npm create vite: every template in its own pod

Each card boots its own Nodepod and runs create, npm install, npm run dev, then fetches the page, its entry modules and their pre-bundled dependencies through the dev server. Query options: ?only=react-ts,svelte, ?concurrency=4, ?manual=1. A browser tab can only hold so many WebAssembly memories (each dev server keeps Rolldown's, Tailwind's...): if a card fails with "Cannot allocate Wasm memory", lower ?concurrency=. tests/browser/create-vite-all.spec.ts runs this page headless.
